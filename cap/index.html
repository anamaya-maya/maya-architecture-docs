CAP catalogue — how to read

CAP = Capability (what Maya must do). SDD = Software Design Document (how the system is designed). ADR = Architecture Decision Record (why a technical choice was locked). Maya AI + training honour the same records — if behaviour is wrong, we detail the CAP, not hope the model invents it.

7 CAPs = Asto loop One page each Review → freeze SDD
Asto asked: “gimana bacanya untuk make sure maya melakukan ini?” Use the checklist below. Each Asto bullet maps to one CAP. Open the CAP → read Must / Must not → run the verify probes. ChatGPT review: paste this page URL + Asto’s bullet list and ask “is every bullet covered by a CAP?”

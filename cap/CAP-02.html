CAP-02 — Complete slots → trip summary

Capability record Maya (and training) must honour. Part of the flight / hotel / both booking loop.

CAP-02 CAP MVP freeze candidate
Asto source (verbatim). setelah dapat intensi dia lengkapi semua yang diperlukan untuk dijadikan summary

Must

  • Collect every slot required for the active intent before offering Search.
  • Flight slots: origin, destination, date(s), passengers (and return if round-trip).
  • Hotel slots: area/city, check-in/out or nights, guests/rooms as needed.
  • Show a clear trip summary and wait for Search (ADR-001).

Must not

  • Call OMS search before the summary is confirmed / Search clicked.
  • Fill missing slots with invented cities, dates, or prices.

How to verify Maya does this

Use these probes. If any fail, the CAP is not detailed enough or runtime is wrong — tighten the CAP, do not “train around” it.

  • After intent, Maya asks only for missing slots (one at a time preferred).
  • Summary lists all filled slots; CTA is Search, not Book.

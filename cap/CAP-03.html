CAP-03 — Summary edit without Search

Capability record Maya (and training) must honour. Part of the flight / hotel / both booking loop.

CAP-03 CAP MVP freeze candidate
Asto source (verbatim). kalau user saat disajikan summary tidak click search berarti ada data summary yang perlu diubah berdasarkan chating user
Also (zip24): saat “no-edit chat” AI berusaha tangkap logika user dan sajikan ulang summary.

Must

  • If summary is shown and user chats instead of clicking Search (“no-edit chat”), treat chat as edits to summary slots.
  • Re-catch user logic and re-render the updated summary.
  • Stay in pre-search state until Search is clicked.

Must not

  • Trigger OMS search from free-chat while summary is pending Search.
  • Ignore the edit and keep stale summary values.

How to verify Maya does this

Use these probes. If any fail, the CAP is not detailed enough or runtime is wrong — tighten the CAP, do not “train around” it.

  • Summary shown → user: “tanggalnya 12 Oktober” → summary updates date; still no search results yet.
  • User: “ganti ke hotel bintang 4” → prefs recorded for next search; still waiting Search if not clicked.

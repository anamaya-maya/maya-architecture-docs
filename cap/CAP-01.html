CAP-01 — Detect user intent

Capability record Maya (and training) must honour. Part of the flight / hotel / both booking loop.

CAP-01 CAP MVP freeze candidate
Asto source (verbatim). di awal dia cek intensi user

Must

  • Classify every new trip request as exactly one of: flight, hotel, or both.
  • State the detected intent in the trip summary in plain language.
  • If the message is ambiguous between flight and hotel, ask one clarifying question — do not search yet.

Must not

  • Invent a fourth product job (visa encyclopedia, open Q&A, weather chat as primary).
  • Silently switch intent without confirmation (see CAP-04).

How to verify Maya does this

Use these probes. If any fail, the CAP is not detailed enough or runtime is wrong — tighten the CAP, do not “train around” it.

  • User: “cari hotel Seminyak 2 malam” → Maya treats intent as hotel (or both only if flight also stated).
  • User: “CGK ke Jogja besok” → intent flight.
  • User: “liburan Bali” alone → ask flight / hotel / both before searching.
